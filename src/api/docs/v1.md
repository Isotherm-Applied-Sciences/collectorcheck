# CollectorCheck API v1

## Overview
CollectorCheck v1 exposes a stable, versioned API surface for ingestion, metadata extraction, and cloud processing.

All API responses follow the formal contract:

```json
{
  "ok": boolean,
  "data": object | null,
  "error": {
    "code": string,
    "msg": string,
    "data": object | null
  } | null
}
```

## Methods

### v1.processAll()
Runs the full ingestion → metadata → cloud pipeline.

Returns:
- `ok: true` with full engine output
- `ok: false` with API error envelope

### v1.snapshot()
Returns the ingestion snapshot.

### v1.extractMetadata(file)
Extracts metadata for a single file.

## Contract Validation
All API responses can be validated using:

```js
v1.validateApiResult(result)
```

## Versioning
This is the v1 API surface. Future versions will be published under `src/api/v2`, `src/api/v3`, etc.
